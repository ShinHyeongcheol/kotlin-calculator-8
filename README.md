# kotlin-calculator-precourse

# 미션 내용
문자열을 입력받고, 숫자를 추출하여 각 숫자를 더하는 계산기를 만든다.

# 구현 기능 정리
1. camp.nextstep.edu.missionutils 라이브러리를 이용해 문자열 입력받기
2. 입력받은 문자열에서 쉼표(,)와 콜론(:)을 구분자로 각 숫자를 분리해 값을 반환받기
3. 덧셈 결과를 출력하고, 이때 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고 종료하기
4. 기존 구분자 외에 커스텀 구분자를 지정해보기

# 입출력 요구사항
## 입력
- 구분자와 양수로 구성된 문자열

## 출력
- 결과 : N
- 이때 N은 양수의 합
